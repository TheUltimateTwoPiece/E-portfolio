# Portfolio assets

## Files in this folder

| File / Folder     | Purpose                                                |
| ----------------- | ------------------------------------------------------ |
| `logo.svg`        | **PLACEHOLDER logo.** Swap with your real logo.        |
| `portrait.jpg`    | Optional personal photo, used in the About section.    |
| `certs/`          | Drop certificate images (`cert-1.jpg` … `cert-6.jpg`). |
| `competitions/`   | Drop competition photos; edit captions in `lib/data.ts`. |

## How to swap the logo

The current `logo.svg` is a placeholder monogram with a "PLACEHOLDER"
label so it's obvious in previews. Replace it with your actual logo SVG
and it will appear in the navigation and Hero automatically.

## How to swap the portrait

Drop a `portrait.jpg` (or `.png`) into this folder. Currently
`main photo.jpeg` was renamed to `portrait.jpg` automatically by the
build setup — replace it with your preferred portrait if you want.
